# AIChatGame — ИИ-чат в Unity через OpenRouter

Unity 6 (6000.6.3f1) приложение-чат. Отправляет сообщения бесплатным моделям OpenRouter и автоматически переключается на следующую модель при лимите или недоступности.

## Настройка API-ключа

1. Создайте ключ на <https://openrouter.ai/keys>.
2. Скопируйте `AIChatGame/Assets/StreamingAssets/openrouter_config.example.json` в `openrouter_config.json` рядом с ним.
3. Вставьте ключ в поле `apiKey`.

Файл `openrouter_config.json` указан в `.gitignore` и не попадает в репозиторий. Ключ внутри клиентской сборки не защищён — для публичного приложения нужен серверный посредник.

## Запуск

Откройте папку `AIChatGame` в Unity, затем сцену `Assets/Scenes/ChatScene.unity` и нажмите Play.
Сцену можно пересобрать с нуля: меню **Tools → AI Chat → Build Chat Scene**.

## Структура

| Скрипт | Ответственность |
|---|---|
| `ChatUI` | Поле ввода, кнопки «Отправить»/«Очистить», Enter, статус, защита от повторной отправки |
| `ChatHistory` | Системный промпт и история (последние 10 сообщений, системный промпт не обрезается) |
| `OpenRouterClient` | HTTP-запрос через `UnityWebRequest`, таймаут, разбор ответа и ошибок, цикл ротации |
| `ModelRotator` | Список моделей, начало с последней успешной, тестовый режим имитации 429 |
| `ChatMessageView` | Пузырь одного сообщения |
| `Editor/ChatSceneBuilder` | Сборка сцены и UI |

## Модели (проверены реальными запросами 29.10.2026)

1. `nvidia/nemotron-3.5-super-vl:free`
2. `dots-studio/dots-3-note-preview:free`
3. `poolside/laguna-s-2.1:free`
4. `recursive/flint-v1.0:free`
5. `nvidia/nemotron-3-ultra-550b-a55b:free`
6. `google/gemma-4-31b-it:free` — часто отвечает 429 (лимит у провайдера), поэтому стоит последней

Не подошли: `thinkingmachines/inkling:free` (403, доступна только агентным приложениям), `google/gemma-4-26b-a4b-it:free`, `liquid/lfm-2.5-2.6b:free`, `xingchen-agi/xing4.0-29b-a4b:free` (429 при проверке).

Список редактируется в Inspector компонента `ModelRotator` на объекте `ChatManager`.

## Алгоритм ротации

Один пользовательский запрос — максимум один проход по списку (не больше N попыток). Каждая попытка отправляет ту же историю, меняется только `model`.

| Ситуация | Действие |
|---|---|
| 200 с текстом | Успех, модель запоминается как стартовая для следующего запроса |
| 200 без текста | Следующая модель |
| 429, 408, 404, 403, 5xx, таймаут | Следующая модель |
| 400 с упоминанием модели (неверный slug) | Следующая модель |
| 400 прочее | Стоп: ошибка запроса |
| 401 | Стоп: проверьте ключ |
| 402 | Стоп: нет кредитов |
| Нет сети | Стоп: проблема соединения |

При ошибке вопрос не записывается в историю, а возвращается в поле ввода для повторной отправки.

Для проверки ротации без расхода лимита включите `Simulate 429 On First Attempt` в `ModelRotator`.
